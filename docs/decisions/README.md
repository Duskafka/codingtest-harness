# 결정 대장

> 사람이 정하는 문서예요. 사람이 정한 결정은 사람이 직접 고치거나, 에이전트가 `docs/` 브랜치의 문서 전용 PR로 반영해요 (`docs/workflow.md` 4장). 에이전트의 제안은 `NNN-제목.md` 결정 제안서로 해요 (템플릿: `000-template.md`).

결정은 두 종류예요.

- **확정 (D):** 이미 정해진 것. 에이전트는 그대로 따르고, 바꾸자고 하려면 결정 제안서를 써요.
- **열린 결정 (OD):** 아직 정해지지 않은 것. 걸린 단계는 결정 전에 그 부분을 구현하지 않아요.

| D20 | 스터디는 기수(기본 4주) 단위로 운영하고, 혼자 쓰기 모드를 지원한다                                                                             | 짧게 끊을수록 참여율이 높다 [S18]                                                              |
| D21 | 웹훅 처리는 P1 '수신 기록 후 바로 처리' → P2 'inbox + 비동기 워커 + 누락 복구'                                                                 | 먼저 운영하고, 실제 누락 데이터로 개선 전후를 비교한다                                         |

| D23 | 베이스 패키지 `com.duskafka.studybot`, 기본 브랜치 `master`                                                                                    | 첫 커밋에서 정함                                                                               |
| D24 | 하네스 방식: 에이전트가 구현하고 판단을 기록, 사람이 검토하고 결정 (`docs/workflow.md`)                                                        |                                                                                                |

D22(로그인 세션을 DB에 저장)는 OD-01에서 확정했어요 (결정 제안서 002).
