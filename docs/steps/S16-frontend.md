## 목표

화면 1~10(2.6)을 깔끔하게 쓸 수 있는 수준으로 만든다. 오늘 현황과 GitHub 연결 화면에만 공을 들인다. 개발 시간의 20%를 넘기지 않는다.

## 읽을 문서

- `docs/spec/frontend.md` 전체
- `docs/spec/product.md`: 2.5 사용자 여정, 2.6 화면 목록, 2.7 알림·공유 채널
- `docs/spec/api.md`: 4.4 표와 '규칙 변경' 메모, 4.5의 CSRF 항목
- `docs/spec/domain-rules.md`: R2
- `docs/spec/processes/5.08-deadline-reminder.md`: 서비스 워커, iPhone, 권한 요청 시점
- `docs/spec/processes/5.09-share-kakao-discord.md`
- `docs/spec/security.md`: 9.7 '입력과 출력'

## 만들 것

1. **골격:** React + TypeScript + Vite 정적 빌드. springdoc 명세로 API 클라이언트 타입을 만든다 (openapi-typescript 등).
2. **화면 1~10 (2.6).** PR을 이렇게 나눈다.
    1. 골격, API 클라이언트, 랜딩(1), 내 스터디(2)
    2. 스터디 만들기(3), 초대 수락(4)
        - 초대 수락 화면은 규칙 요약과 예정된 변경(`upcomingRules`, 적용 시작일)을 함께 보여 준다.
    3. GitHub 연결(5)
    4. 오늘 현황(6), 내 풀이(7), 면제권(8)
    5. 스터디 설정(9), 알림 설정(10)
        - 규칙 폼은 마지막 예정 버전(`upcomingRules`의 마지막, 없으면 `rule`)으로 채우고, 그 `id`를 `basedOnRuleId`로 보낸다. 409를 받으면 상세를 다시 불러온다 (api.md 4.4 '규칙 변경').
        - 예정된 변경과 적용 시작일(다음 스터디 일부터 / 다음 기수부터)을 보여 준다. 하루 기준 시각이 바뀌면 새 기수 첫날의 길이가 달라진다(18~30시간)고 안내한다 (R2).
3. **PWA:** 매니페스트, 서비스 워커. 서비스 워커는 `push` 이벤트로 알림을 띄우고, 알림을 누르면 오늘 현황을 연다. 오프라인 캐시는 하지 않는다.
4. **알림 권한:** 첫 방문이 아니라 스터디에 가입한 직후처럼 이유가 분명할 때, 사용자가 버튼을 눌렀을 때 요청한다. iPhone은 홈 화면에 추가하라는 안내를 넣는다.
5. **카카오톡 공유:** JavaScript SDK로 공유 카드를 보낸다. 공유가 안 되는 환경에서는 '텍스트 복사'.
6. **CSRF:** 쿠키의 토큰을 `X-XSRF-TOKEN` 헤더로 돌려보낸다 (OD-01 결정을 따름).

## 만들지 않을 것

- 정산(11)·이의함(12)·기록·통계(13)·기수 요약(14) 화면 (P2·P3)
- 오프라인 캐시 전략

## 수용 기준

- [ ] 화면 묶음마다 핵심 흐름을 실제로 눌러 보고 스크린샷이나 동작 기록을 PR에 남긴다
- [ ] 타입 검사와 린트가 통과하고, CI에 프론트 빌드가 들어간다
- [ ] 빌드 결과물에 비밀값이 없다. 들어가는 값은 VAPID 공개키와 카카오 JavaScript 키뿐이다
- [ ] `sw.js`와 `index.html`은 캐시하지 않고, 정적 파일 이름에는 해시가 붙는다
- [ ] `dangerouslySetInnerHTML`을 쓰지 않는다
- [ ] 로그인 전 랜딩에 받는 정보(GitHub ID·이름·프로필 사진)와 개인정보처리방침 링크가 보인다

## 주의할 것

- 서비스 워커에 캐시를 욕심내면 '배포했는데 옛 화면이 뜨는' 문제가 생긴다 (7장).
- 카카오 JavaScript 키는 등록한 도메인에서만 동작한다. 운영 도메인만 등록하고 개발용 앱은 따로 만든다 (5.9).
- 디자인은 깔끔하게 쓸 수 있는 정도까지만.

## 판단 기록이 필요한 곳

- 상태 관리, 라우팅, UI 라이브러리 선택 (가볍게)
- API 응답 모양이 화면과 맞지 않을 때는 백엔드를 바꾸지 말고 PR의 '스펙 변경 제안'이나 별도 이슈로 남긴다
